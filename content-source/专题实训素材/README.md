# 专题实训素材库

本目录用于集中归档实训营全部专题实训的课程素材，并作为后续编制会议手册、学员手册和课程资源包的内部工作区。

## 收录范围

仅收录专题实训课程，不收录前沿讲座、理论课程、案例分享、习题课、参访及结营活动。目前共 11 个专题实训模块：

1. 科研智能体专题实训（一）：从零搭建智能体
2. 科研智能体专题实训（二）：智能体记忆与知识库
3. 科研智能体专题实训（三）：科研工具调用与工作流搭建
4. 科研工具专题实训：从领域方法到 Skill 与 MCP
5. AI4S 专题实训（一）：从科学问题到 AI-ready 任务
6. AI4S 专题实训（二）：构建科研数据 Harness——从科研文献到可信的 AI-ready 数据集
7. 科学模型专题实训（一）：从线性回归理解学习与模型结构
8. 科学模型专题实训（二）：从科学数据到模型选型与可信评测
9. 科学模型专题实训（三）：如何构建领域基座模型与 AI Scientist 系统
10. Agent4S 专题实训（一）：从科研任务到可调用能力——CLI、Skill 与智能体工作流
11. Agent4S 专题实训（二）：从一次运行到持续科研——长时任务、评价闭环与人工接管

## 每个模块应归档的材料

- 讲师确认信息：姓名、单位、职称或身份、联系方式及授权状态；
- 会议手册素材：课程名称、150—300 字课程简介、讲师简介、关键词；
- 教学设计：教学目标、课程大纲、分钟级教学流程、互动与实操安排；
- 教学文件：PPT、讲义、阅读材料、图表及可公开引用来源；
- 实训资源：代码、Notebook、数据样例、环境说明、Starter Kit；
- 学员任务：实训说明、输入材料、提交要求、标准输出或参考答案；
- 运行记录：试讲意见、环境测试、版本信息、已知问题与修改记录；
- 权利边界：公开范围、引用方式、图片和数据授权、保密事项。

## 使用规则

- 日程表仅保留“时间、课程、主讲人及单位”等简明信息，详细内容统一在本目录维护。
- 课程素材按模块独立存放，不把多个课程的 PPT、代码和数据混在同一目录。
- 会议手册使用的文字和图片必须标明版本及授权状态；内部会议记录不得直接作为对外材料发布。
- 外部链接应在模块 README 中登记，并在形成正式手册前核验可访问性和引用边界。
- 网站当前内容种子仍以 v2.1.1 为准；本目录用于课程筹备，不会自动发布到网站。
