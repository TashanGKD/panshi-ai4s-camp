# 磐石实训营短信通知模板设计

## 1. 目标与边界

为“磐石·科学智能（AI for Science）实训营”报名审核流程申请五个国内通知短信模板，并统一使用已审核通过的短信签名“他山青年”。

本次仅申请阿里云短信模板，不发送短信，也不修改网站代码。模板通过审核后，再另行实施网站状态事件与短信发送的可靠对接。

## 2. 申请参数

- 短信类型：通知短信（`TemplateType=1`）
- 关联签名：他山青年
- 业务场景：实训营报名提交、材料补充和审核结果通知
- 场景链接：`https://panshi-ai4s.tashan.chat/`
- 模板变量：无
- 短信正文中的网址、电话号码或其他引流信息：无

模板正文不直接包含网址。这样可以避免新增模板必须补充域名备案材料，并降低运营商对引流信息的拦截风险。短信统一提示学员登录实训营网站查看；网站地址通过既有报名渠道和活动材料提供。

## 3. 模板清单

### 3.1 报名已提交

- 模板名称：实训营报名提交通知
- 模板正文：您的磐石·科学智能实训营报名信息已提交，现已进入审核队列，请登录实训营网站查看审核进度。
- 触发场景：学员首次正式提交报名表；学员按要求补充或修改信息后重新提交。

### 3.2 补充报名材料

- 模板名称：实训营补充材料通知
- 模板正文：您的磐石·科学智能实训营报名材料需要补充，请登录实训营网站查看具体要求并重新提交。
- 触发场景：管理员将报名状态调整为“需要补充材料”。

### 3.3 审核通过

- 模板名称：实训营审核通过通知
- 模板正文：您的磐石·科学智能实训营报名已审核通过，请登录实训营网站个人中心查看录取信息并获取报到二维码。
- 触发场景：管理员将报名状态调整为“审核通过”。

### 3.4 进入候补

- 模板名称：实训营候补通知
- 模板正文：您的磐石·科学智能实训营报名已进入候补名单，请登录实训营网站查看最新状态。
- 触发场景：管理员将报名状态调整为“候补”。

### 3.5 未通过审核

- 模板名称：实训营审核结果通知
- 模板正文：您的磐石·科学智能实训营报名本次未通过审核，请登录实训营网站查看申请状态。
- 触发场景：管理员将报名状态调整为“未通过审核”。

## 4. 统一申请说明

用于“磐石·科学智能（AI for Science）实训营”报名审核流程中的系统通知。短信仅发送给已在实训营网站注册并主动提交报名信息的用户，用于告知报名提交、补充材料、审核通过、候补或未通过审核等状态。短信不包含营销推广内容，不包含联系方式或链接。完整示例与模板正文一致。业务场景页面为 https://panshi-ai4s.tashan.chat/ 。

## 5. 审核与使用约束

1. 五个模板分别提交，任一模板申请间隔不少于 30 秒。
2. 只有 `TemplateStatus=1` 的模板才可进入生产配置。
3. “他山青年”签名当前已审核通过；运营商报备状态仍需在正式发送前复核。
4. 模板通过审核后不得修改。若文案变化，应申请新模板并在生产配置中显式切换。
5. 本次模板申请成功不代表短信已经发送，也不代表运营商最终送达。
6. 后续网站对接必须对状态事件建立幂等记录，避免管理员重复操作或服务重试造成重复短信。

## 6. 验收标准

- 阿里云返回五个模板代码和对应工单号。
- 五个模板均可通过 `GetSmsTemplate` 查询审核状态。
- 模板名称、正文、类型、关联签名和场景链接与本文件完全一致。
- 未执行任何 `SendSms` 或 `SendBatchSms` 操作。
