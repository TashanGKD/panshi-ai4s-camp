# 实训营报名身份信息与 AI4S 问题池设计

## 目标

在既有手机号账号、草稿保存、正式提交和后台审核链路上，调整报名表的信息组织方式，使身份信息符合真实学习或工作状态，并以结构化方式采集学员技术基础、项目经历和 AI4S 问题兴趣。

本设计补充既有《实训营报名表与单位名录设计》，不改变已经确认的高校名录、国科大培养单位名录、附件上传和审核状态机。

## 基本原则

- 姓名字段默认留空，不使用账号显示名或“实训营学员”等占位文字回填。
- 首先选择当前身份，再按身份显示相应字段；不向申请人展示与其身份无关的问题。
- 单位、岗位和专业技术职称分开采集，不把企业职务与国家专业技术职称混为一类。
- 已提交报名表保持不可变；字段升级只作用于新建或尚未提交的草稿。
- 报名端的问题池不显示出题人。出题人与所属单位仅作为后台管理信息保留。
- 问题池题目可以按出题人在后台归档，但每一个独立研究方向均为独立选项，不合并。

## 一、身份信息

### 1. 当前身份

单选项：

1. 本科生
2. 硕士研究生
3. 博士研究生
4. 在站博士后
5. 在职人员
6. 其他

### 2. 本科生

- 姓名：必填，默认空白。
- 手机号：由当前账号带入，只读。
- 电子邮箱：必填。
- 所在学校：必填，使用可搜索高校名录。
- 院系：必填。
- 专业：必填。
- 研究兴趣：选填。

### 3. 硕士研究生、博士研究生

- 姓名：必填，默认空白。
- 手机号：由当前账号带入，只读。
- 电子邮箱：必填。
- 所在学校：必填，使用可搜索高校名录。
- 院系或培养单位：必填。
- 专业：必填。
- 研究方向：必填。
- 选择“中国科学院大学”时，培养单位必须从国科大培养单位名录中选择。

### 4. 在站博士后

- 姓名、手机号、电子邮箱。
- 设站或依托单位：必填。
- 博士后科研流动站或工作站：必填。
- 一级学科或专业领域：必填。
- 研究方向：必填。
- 合作导师：选填。

### 5. 在职人员

- 姓名、手机号、电子邮箱。
- 工作单位：必填。
- 岗位或职务：必填，自由填写，例如“副总经理”“研发总监”“算法工程师”“科研助理”。
- 专业技术职称：选填，选项为“无、初级、中级、副高级、正高级、其他”。
- 具体职称：选填，例如“研究员”“高级工程师”“教授”。

### 6. 其他

- 姓名、手机号、电子邮箱。
- 身份说明：必填。
- 所在单位：选填。
- 专业领域或研究方向：选填。

## 二、编程、数据分析和人工智能基础

该项不使用自由文本问答，而采用逐项三级评价：

1. 不了解
2. 了解并会简单使用
3. 熟练使用并掌握相关原理

评价项目：

- Python
- C/C++
- R
- MATLAB
- SQL/数据库
- Linux/Shell
- Git/版本控制
- 数据分析与可视化
- 机器学习/深度学习
- 大语言模型
- 智能体开发
- 其他

“其他”允许填写技术、工具或语言名称，并选择对应等级。Julia 不列入固定项目。

## 三、项目经历

“已有科研、竞赛、工程或项目经历”保留为长文本字段，但改为选填。

## 四、AI4S 问题选择

- 申请人从问题池选择 1—3 个问题。
- 每个选项默认显示题目，可展开查看一段正式、学术化的简介。
- 另设“本人希望提出和研讨的科研问题”，允许选填一个自拟题目或问题说明。
- 问题池选择与自拟问题可以同时提交。
- 报名端不展示出题人；后台可保留出题人、单位、原始材料和外部链接。

## 五、问题池正式文案

### 1. 多源灾害监测数据的智能预处理

围绕 GNSS、水位、降雨、变形、地震动及现场图像等多源监测数据，研究通信中断、设备故障和信号干扰造成的缺失数据重构，区分设备异常、环境干扰与灾害突变，并改善夜间及雨雪雾条件下的图像质量。重点关注重构结果的不确定性和图像恢复的真实性，为灾害识别与预警提供可靠的数据基础。

### 2. 基于数字孪生与路径规划的多灾种监测系统优化

面向滑坡、崩塌、泥石流等多灾种监测需求，构建包含区域地形、潜在灾害源、传播路径和监测设备的动态数字孪生体，将固定设备布设、移动设备巡检和分阶段采样转化为多目标优化问题，在成本与运行条件约束下，提高对灾害源区、传播路径和关键节点的覆盖能力、信息增益与预警提前量。

### 3. 面向灾害链与群发灾害的基础模型及迁移预警

针对真实灾害样本稀缺、区域差异显著和灾害链观测分散等问题，利用长期未标注监测数据学习正常状态下的时空规律，并结合少量真实事件识别灾害孕育、加速和失稳阶段。通过迁移学习与领域适应，将历史事件、模拟数据和已有区域知识迁移至缺少历史样本的新区域，实现具有证据说明和置信度评估的迁移预警。

### 4. 基于常规健康数据的抑郁风险早期识别

利用人口学特征、生活方式、体检指标及实验室检查结果等常规健康数据，构建抑郁风险识别模型，比较不同统计学习和机器学习方法的预测表现，并分析关键影响因素及个体差异。研究应重视样本不平衡、模型校准、可解释性和跨人群泛化能力，探索人工智能辅助心理健康风险筛查的可行路径。

### 5. 面向 AI4S 的科研论文搜索智能体

面向研究对象、方法、数据集和实验结论等多重约束下的复杂文献检索任务，构建能够自主制定检索策略、调整检索词、扩展引文网络、筛选论文并提取证据的科研论文搜索智能体。重点研究检索过程记录、证据核验、来源追溯和搜索终止机制，使形成的研究结论能够回溯至具体论文及其证据位置。

### 6. 基于 PyTRIO 与 SwanLab 的 AI4S 智能体实验闭环

围绕科研智能体训练过程中的数据准备、奖励设计、模型训练、实验记录和效果评测，研究如何利用 PyTRIO 完成后训练代码生成与调试，并通过 SwanLab 记录模型配置、训练指标、运行日志和实验环境，形成“训练—观测—分析—复盘—迭代”的实验闭环，提高 AI4S 实验的透明度、可比较性和可复现性。

### 7. 基于智能体的科研文献 AI-ready 数据集构建

针对科学数据分散于论文正文、表格、图件和补充材料，且数据结构、单位和语义表达不一致的问题，研究利用智能体完成文献解析、信息抽取、字段标准化、冲突检测和证据定位，形成结构化、机器可读、来源可追溯的数据集。重点保障字段定义一致、原始证据可核验，以及无法获得证据的信息被如实标记。

### 8. 基于公开高通量实验数据的酰胺偶联反应产率预测与条件推荐

利用公开高通量酰胺偶联反应数据，构建底物、试剂和反应条件的分子表示，比较不同机器学习方法在产率预测和反应条件排序任务中的表现。研究应关注模型对细微结构变化的敏感性、对实验不确定性的稳健性以及对未知底物的泛化能力，为反应条件筛选和实验设计提供参考。

### 9. （产业赛题）数据共情者——面向消费者需求理解的 AI 管家

面向美妆消费服务中用户需求表达多样、交互信息分散及个体偏好差异显著等问题，研究融合自然语言处理、多轮对话建模与用户需求表征的智能服务方法。重点探索消费者意图识别、上下文信息整合、个性化响应生成及服务效果评价，构建能够准确理解用户需求并提供适配性服务的人工智能交互系统。

### 10. （产业赛题）信任守护师——面向美妆内容真实性识别的 AI 卫士

面向生成式人工智能环境下美妆内容真实性、可靠性与可追溯性问题，研究融合文本、图像和视频信息的多模态内容分析方法。重点开展人工生成与篡改内容识别、误导性信息检测、判断依据追溯及风险表征，构建具有可解释性和可信度评估能力的内容鉴真系统。

### 11. （产业赛题）无界体验家——人工智能驱动的未来美妆体验

面向美妆消费体验的数字化与智能化发展需求，研究多模态感知、生成式人工智能和智能体技术支持下的新型人机交互方法。围绕个体特征理解、需求建模、交互内容生成和体验效果评价，探索具有个性化、适应性与可验证性的美妆智能应用方案。

### 12. 多模态心理—神经数据驱动的心理健康预测智能体

融合心理健康问卷、认知行为指标、语音文本、脑影像及纵向随访数据，构建能够持续接收新信息并动态更新的个体心理健康表征，预测抑郁、焦虑等心理状态、风险水平及变化轨迹。研究应关注多模态信息对齐、缺失数据处理、个体差异解释和预测不确定性。

### 13. 面向个体心理状态演化的智能仿真系统

基于个体多模态特征和纵向状态变化数据，研究心理状态在不同时间、情境刺激或干预条件下的转移规律，构建个体化心理状态智能仿真原型。系统应能够模拟状态变化方向和可能轨迹，并通过随访或实验数据进行初步验证，同时明确仿真结果的不确定性及其与临床判断之间的边界。

### 14. 高端 MEMS 器件智能设计

面向高端微机电系统器件研发中结构设计、多物理场仿真、工艺校验和性能优化相互割裂的问题，研究利用多模态模型与智能体完成需求解析、候选结构生成、仿真工具调用、结果诊断和迭代优化，并将专家设计经验封装为可执行技能，持续沉淀标准化、可追溯的 MEMS 设计数据。

### 15. 复杂工程器件的智能设计与数据闭环

面向复杂工程器件设计涉及多学科知识、多类专业软件和多轮人工迭代的特点，构建从需求理解、方案生成、结构建模、多物理场仿真、结果评价到迭代优化的可验证闭环。重点研究专业工具调度、物理约束校验、失败方案记录和专家知识复用，形成可用于模型训练与评测的工程设计数据。

### 16. 基于人工智能的土壤微塑料降解微生物组设计

整合微塑料—微生物互作、塑料际微生物群落及生物降解研究证据，利用人工智能识别具有潜在微塑料降解能力的关键微生物、功能特征及组合规律，提出可供后续实验验证的候选微生物组方案。研究应兼顾降解潜力、生物学依据、生态安全性和候选方案的可重复计算与优先级排序。

### 17. 面向 AI-ready 的土壤微塑料微生物组数据库构建与知识发现

系统整理土壤微塑料及塑料际微生物组研究，建立微塑料类型、环境条件、微生物组成、群落响应和功能信息之间的结构化关联，形成来源可追溯、机器可读且可复用的数据集。在此基础上，探索跨研究的微塑料—微生物关联规律，为降解微生物筛选和生态风险研究提供数据基础。

### 18. 面向科学垂直领域的 AI-ready 数据集构建

针对科学文献数据结构复杂、表达形式多样且高度依赖专家整理的问题，研究一套可迁移至不同学科的智能体数据构建方法，完成文献解析、实体识别、关系抽取、单位标准化、质量校验和证据追溯。以 Stella 项目为基础，探索兼顾数据整理效率、科学准确性与领域可扩展性的通用工作流程。

### 19. 基于生态学文献的土壤种子库 AI-ready 数据集构建

利用智能体解析土壤种子库研究论文的正文、方法、结果、表格、图件及补充材料，识别研究地点、样地处理、采样时间、采样深度、种子库密度、多样性及物种记录等信息，形成结构统一、语义明确且来源可追溯的数据集。重点处理跨文献字段差异、单位统一、多处证据合并和缺失信息标记，为生态学综合分析提供可靠的数据基础。

## 六、交互与存储

- 技术基础采用结构化对象保存，不拼接成难以统计的长文本。
- AI4S 问题池采用稳定问题 ID 保存，展示标题与简介来自已发布报名表版本。
- 多选问题由后端校验最少 1 项、最多 3 项。
- 自拟科研问题为独立选填长文本，不占问题池 1—3 项名额。
- 题目简介可在选择器中展开；移动端不得依赖悬停操作。
- 尚未提交的旧草稿如姓名等于系统占位值“实训营学员”，升级时清空；用户真实填写的姓名不得覆盖。
- 管理后台和导出结果应分别展示身份条件字段、技术能力等级、问题池题目和自拟问题。

## 七、兼容性与非目标

- 不修改已提交报名快照。
- 不在首版报名端展示出题人、题目负责人或联系方式。
- 不要求申请人填写完整研究方案、技术路线或预期成果。
- 不把问题池简介扩展为基金申请书式多章节正文。
- 不在本次任务中更换账号、附件、审核和本地文件存储架构。
